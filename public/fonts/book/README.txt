Fonts used by the publishing tools (PDF export, covers, mockups).

"EFY Book Serif" (Regular, Bold, Italic, Bold Italic), a modified version of Lora - Copyright 2011 The Lora Project Authors (https://github.com/cyrealtype/Lora-Cyrillic). SIL Open Font License 1.1 (OFL.txt).
Poppins (Light, Regular, Bold) - Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins). SIL Open Font License 1.1 (OFL.txt).

Modified versions: static instances of the Lora variable font, subset to Latin, Latin Extended, combining marks, punctuation and currency symbols, hinting removed. The modified Lora files are renamed "EFY Book Serif" because "Lora" is a Reserved Font Name under the OFL.
